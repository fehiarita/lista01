# 📚 Exercícios de Estrutura de Dados em C

Este repositório contém uma coleção de exercícios práticos desenvolvidos por mim para a faculdade. O foco principal é a implementação de estruturas de dados dinâmicas (Pilha e Fila) e a aplicação de lógica de programação para resolver problemas reais.

## 🚀 O que este repositório contém?

Aqui estão os principais projetos e o que cada um faz:

1.  **Calculadora Fiscal de Produtos**
    *   Cadastra categorias de impostos e produtos.
    *   Calcula o preço final do produto aplicando o desconto do imposto correspondente.
    *   **Estruturas:** Filas dinâmicas e busca por strings.

2.  **Gestão de Alunos e Notas**
    *   Sistema que vincula notas a alunos específicos através de IDs.
    *   Permite calcular médias e filtrar alunos sem notas.
    *   **Estruturas:** Pilha (Alunos) e Fila (Notas).

3.  **Classificador de Pares e Ímpares**
    *   Recebe uma sequência de números em uma pilha.
    *   Separa e distribui esses números em duas filas diferentes (uma para pares e outra para ímpares).
    *   **Estruturas:** Pilha e Fila.

4.  **Sequência de Fibonacci em Pilha**
    *   Calcula a sequência de Fibonacci de forma recursiva.
    *   Armazena os resultados em uma pilha para exibição inversa.
    *   **Estruturas:** Pilha e Recursividade.

5.  **Pilha com Filtro de Paridade**
    *   Um gerenciador de pilha com opção de listar apenas números pares e remover elementos específicos.

## 🛠️ Tecnologias e Conceitos

*   **Linguagem:** C
*   **Alocação Dinâmica:** Uso intensivo de `malloc` e `free` para gestão eficiente de memória.
*   **Ponteiros:** Manipulação de nós em listas encadeadas.
*   **TADs:** Implementação de Tipos Abstratos de Dados (Pilha e Fila).
